# Library Management SQL Project

## 📌 Project Overview

This project analyzes a library/book store database using MySQL.

The project contains books, customers, and orders data.
SQL queries are used to generate useful business insights.

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench
- SQL
- GitHub
